# rmit-attack-fabric

The project gets logs in Snort and stores them on the Hyperledger Fabric. The logs are generated by Snort rules which define a few cyber attack types such as DoS, Port Scanning, .etc.

# Prerequisites

[ Link](https://hyperledger-fabric.readthedocs.io/en/release-2.2/prereqs.html)

# Start the network

```
cd first-network
./network.sh up createChannel
```

# Deploy the chaincode

```
cd first-network
./network.sh deployCC -ccn log-chaincode -ccp ../chaincode -ccl typescript
```
